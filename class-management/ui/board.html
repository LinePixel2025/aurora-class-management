数据统计

旧事务保留最近 7 天，可用 Agent 调用 list_tasks 查回。

给 Agent 用

  • /class 打开管理台；/week-plan 让 Agent 总结今日计划。
  • 事务按天：add_task 默认今天，传 date 可排未来某天；旧事务保留 7 天。
  • 值日按周：set_duty_week 指定本周组，set_duty_groups 编辑分组与轮换顺序。
  • 每天例行：set_routines 整表写入基础安排，也可在「安排 → 基础安排」逐条增删改。
  • 安排提醒：安排可勾选「到点前提醒」（remind / remindLead），需在插件设置里开启安排提醒。
  • Agent 修改后页面与小组件会自动刷新，无需手动刷新。
